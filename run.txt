ShopLab - Local Lab

1. Open a PowerShell terminal in this project folder.
2. Create and activate a virtual environment:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
3. Install dependencies:
   pip install -r requirements.txt
4. Start the application:
   python app.py
5. Open:
   http://127.0.0.1:5000
